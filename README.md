# Eetkalender (PWA)

Mobiele eetkalender — week/maand, recepten, boodschappen, cloud-sync (Supabase).

## Live (na GitHub Pages)

`https://<jouw-user>.github.io/eetkalender/`

## Installeren (PWA)

- **Android Chrome:** menu → **App installeren** / Toevoegen aan startscherm  
- **iPhone Safari:** Deel → **Zet op beginscherm**

## Privacy

- Geen secrets in deze repo (keys alleen in de app op het toestel).  
- Data zit in jullie eigen Supabase-project.  
- Deellink / Instellingen koppelen de cloud.
